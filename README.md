# Akai 25-Key Performance Method

An independent, illustrated, offline-friendly learning website for the Akai MPK Mini Play mk3.

Learn chord inversions, blues I–IV–V, major and minor jazz ii–V–I, scales, arpeggios, and one-handed accompaniment for singers and guitarists.

## Start here
- [Website homepage](index.html)
- [Four performance lessons](lessons/index.html)
- [Illustrated Akai handbook](akai_howto_v1_illustrated.html)

No build step, external runtime dependencies, account, or tracking. Keep the site files together for offline use.
